Project: FRP Unlocked - Admin Panel

To run:
1. Install Flask: pip install flask werkzeug
2. Run: python app.py
3. Visit: http://localhost:5000/admin
4. Login with:
   - Username: admin
   - Password: admin123

Folder structure:
- app.py = Flask app
- config.py = Admin credentials
- templates/ = HTML pages
- static/ = CSS styles
- uploads/ = APK files folder (optional)
